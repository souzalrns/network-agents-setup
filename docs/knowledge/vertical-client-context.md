# Template — Contexto de cliente (verticais)

Verticais usam **ficha `[CLIENT]`** + regras do vertical — não inventam o cliente.

## Ficha mínima (YAML)

```yaml
cliente:
  nome_marca: ""
  sites: []
  mercados: []
  oferta_em_uma_frase: ""
  icp: ""
  posicionamento: ""
  tom_de_voz: ""
  claims_proibidos: []
  prova_disponivel: []
  brand_kit: ""
  canais_ativos: []
  objetivos_90d: []
  restricoes_legais: []
  contactos_aprovacao: ""
```

## Extras por vertical

| Vertical | Extra |
|----------|--------|
| brand-guard | Desvios graves; palavras banidas |
| social IG/TikTok | Pilares, frequência, hits reais |
| trafego-pago | Tracking, KPI, orçamento |
| producao-audiovisual | Material, restrições de rodagem |
| tiktok-shop | Catálogo, preços, stock |
| conteudo-calendario | Campanhas, sazonalidade |
| estrategista-marca | Concorrentes, histórico |

## Regras

Campo vazio → pedir · prova só se na ficha · YMYL manda sobre criatividade · horizontais usam a mesma ficha.
