# Template — Contexto de cliente (verticais)

Os verticais **não** levam knowledge pack genérico de mercado: levam **ficha do cliente**. Preencher e injetar em `[CLIENT]`.

---

## Ficha mínima

```yaml
cliente:
  nome_marca: ""
  sites: []
  mercados: []          # PT, BR, ...
  oferta_em_uma_frase: ""
  icp: ""
  posicionamento: ""    # ou link para doc
  tom_de_voz: ""
  claims_proibidos: []
  prova_disponivel: []  # números, casos, certificações — só reais
  brand_kit: ""         # cores, tipo, logos
  canais_ativos: []     # IG, TikTok, paid, ...
  objetivos_90d: []
  restricoes_legais: []
  contactos_aprovacao: ""
```

## Por vertical — o que acrescentar

| Vertical | Extra |
|----------|--------|
| brand-guard | Guidelines de tom/visual; o que é desvio grave |
| social-instagram / tiktok | Pilares, frequência, o que já performou (se houver dados) |
| trafego-pago | Tracking, KPI, orçamento, learnings |
| producao-audiovisual | Stock de material, restrições de rodagem |
| tiktok-shop | Catálogo, preços, políticas de stock |
| conteudo-calendario | Campanhas fixas, sazonalidade, dependências de produção |
| estrategista-marca | Histórico de posicionamento, concorrentes nomeados |

## Regras

- Campo vazio = agente deve **pedir**, não inventar
- Atualizar a ficha quando a prova ou a oferta mudar
- Horizontais usam a mesma ficha + knowledge pack da especialidade
