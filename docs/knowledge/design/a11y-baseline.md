# A11y baseline (lab)

Checklist mínimo para `ui_spec` e `design_critic`:

- [ ] Contraste texto/fundo adequado (alvo WCAG AA em UI de produto)
- [ ] Foco visível em controlos de teclado
- [ ] Alvo de toque ≥ 44×44 CSS px em mobile
- [ ] Imagens informativas com alternativa textual (quando aplicável)
- [ ] Erros associados ao campo (não só cor)
- [ ] Motion: respeitar redução de movimento se animações forem essenciais ao entendimento
- [ ] Não depender só de cor para significado

Não substitui auditoria formal; define o **mínimo** para `publish_ready` de design pack.
