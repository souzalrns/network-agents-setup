# UX principles (operacional)

## Núcleo

1. **Utilidade antes de estética** — se não resolve o job, falha.
2. **Clareza > densidade** — uma acção primária óbvia por vista crítica.
3. **Feedback** — cada acção tem resposta visível (sucesso, erro, progresso).
4. **Perdão** — erros recuperáveis; confirmações em acções destrutivas.
5. **Consistência** — mesmos padrões para mesmas tarefas.
6. **Acessibilidade funcional** — teclado, leitores, não só contraste visual.
7. **Contexto** — o utilizador não deve memorizar informação entre ecrãs.

## Jobs-to-be-done (formato)

Quando [situação], quero [motivação], para [resultado].

## Teste mental rápido

- O utilizador sabe onde está?
- Sabe o que pode fazer a seguir?
- Sabe o que aconteceu depois de clicar?
