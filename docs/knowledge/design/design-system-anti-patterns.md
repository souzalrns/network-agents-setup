# Anti-padrões — design system / UI agents

1. **Hex no componente** sem token semantic/component.
2. **Um nível de tokens** só (tudo primitive ou tudo "brand-blue").
3. **Happy path only** — sem disabled/loading/error.
4. **AI slop UI** — cards genéricos, gradientes aleatórios, sem hierarquia.
5. **UX dentro do UI agent** — inventar passos de jornada.
6. **Marketing copy** como microcopy de erro.
7. **Ignorar handoff** — "fica bonito" sem nomes de tokens.
8. **Figma-only truth** sem espelho em tokens legíveis por agent.
9. **Acessibilidade como sticker** — sem checklist.
10. **Mesh de agents** — UI a invocar UX/dev por conta própria (o plan orquestra).
