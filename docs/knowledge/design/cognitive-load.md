# Carga cognitiva (UX)

## Tipos

| Tipo | Significado | Mitigação |
|------|-------------|-----------|
| Intrínseca | Dificuldade da tarefa | Dividir passos, progressive disclosure |
| Extrínseca | Ruído da interface | Menos opções simultâneas, hierarquia |
| Germânica | Esforço útil de aprendizagem | Onboarding curto, exemplos |

## Regras práticas

- Máximo **uma** acção primária por vista crítica.
- Formulários longos → secções ou steps com progresso.
- Evitar escolher entre >7 opções equivalentes sem agrupamento.
- Mensagens de erro junto do campo, não só no topo.
- Não exigir memória entre ecrãs não adjacentes.

## Red flags no fluxo

- Três modais seguidos para uma tarefa simples.
- Jargon interno sem glossário.
- Dados repetidos que o sistema já tem.
