# Media buying — knowledge (lab)

## Princípios

1. **Recommend ≠ execute** — spend só após HITL.
2. **Stop-loss** antes de escala.
3. **Uma hipótese por ad set** quando possível.
4. Tracking incompleto = não optimizar para vanity metrics.
5. Compliance de sector (saúde, financeiro, legal) é blocker.

## Estrutura mínima

```text
Campaign (objective)
  Ad set (audience + budget + placement)
    Ad (creative + copy)
```

## Stop-loss (exemplos de política — ajustar por cliente)

- Sem eventos de conversão após N budget → pausar.
- CPA > X× target por Y dias → pausar ou matar criativo.
