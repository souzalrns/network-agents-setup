# AI Findability — multi-sistema (nao so Google)

## Principio

**Item 13 / AI Findability** optimiza para **sistemas que leem, citam e recomendam** conteudo:

| Familia | Exemplos (nao exaustivo) |
|---------|---------------------------|
| Assistentes conversacionais | ChatGPT, Claude, Gemini, Copilot |
| Resposta + fontes | Perplexity, modos com citacoes |
| Overviews / AI search | Google AI Overviews, equivalentes noutros motores |
| Agents / RAG internos | qualquer pipeline que recupere e sintetize a tua peca |

**SEO classico (rankings em SERP)** continua util e **complementar**. Nao e o unico alvo do Item 13.

## O que e comum a GPT, Claude, Gemini, etc.

1. **Texto legivel** no HTML (nao so imagem ou JS vazio)  
2. **Resposta directa** cedo (answer-first)  
3. **Entidades e termos estaveis**  
4. **Pergunta → resposta** (FAQ ou equivalente)  
5. **Claims claras** (citaveis, nao so tom de marca)  
6. **Estrutura de headings** que mapeia intencoes  

Nada disto e "truque do Google": e higiene para **qualquer** modelo que condensa a web ou a tua base.

## O que evitar no discurso

| Evitar | Preferir |
|--------|----------|
| "Rankear no Google" como unico KPI do Item 13 | "Ser encontrado, citado e recomendado por sistemas de IA" |
| "Garantia de aparecer no ChatGPT" | "Aumentar probabilidade de extracão/citacao fiel" |
| Confundir Item 13 com campanha de Ads | Item 13 = estrutura de conteudo + critic |
| Optimizar so para um vendor | Checklist vendor-agnostico + notas por superficie se preciso |

## Relacao com SEO

```text
SEO (crawling, index, rankings, Core Web Vitals, ...)
        + 
AI Findability / Item 13 (citabilidade multi-modelo)
        =
conteudo preparado para humanos + motores + assistentes
```

Usar "Google" nos exemplos so quando o tema for **especificamente** SERP/AI Overview. Nos briefs genericos, falar em **sistemas de IA / assistentes / motores generativos**.
