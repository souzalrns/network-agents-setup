# Video edit checklist (lab)

- [ ] Hook nos primeiros 3s
- [ ] Cortes em silêncios / respirações longas
- [ ] Legendas legíveis (contraste, safe zone)
- [ ] CTA final visível
- [ ] Áudio nivelado; música não enterra voz
- [ ] Ratio correcto (9:16 / 1:1 / 16:9)
- [ ] Sem claim de direitos de música sem fonte
- [ ] Export settings documentados
