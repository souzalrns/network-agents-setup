# Skill — copy_social

## Quando usar

- Variantes por canal (Instagram, TikTok, LinkedIn, …) apos research/trends.

## Processo

1. Mensagem core em uma frase.
2. Uma variante por canal em `channels` (ou 2–3 canais default).
3. CTA so se pedido; sem claims enganosas.
4. Notas de formato (hook, comprimento, hashtags com moderacao).

## done_when

- [ ] Core message clara
- [ ] >= 2 variantes de canal
- [ ] Sem pedido de auto-publish

## Anti-padrões

- Texto identico em todos os canais
- Clickbait ilegal / medical claims sem base
