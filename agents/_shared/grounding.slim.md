# Grounding (versão curta — áreas sem risco: marketing, docs, research)

Mesmas regras da directiva completa (`grounding.directive.md`), em resumo:

1. Factos concretos (números, datas, versões, preços, licenças, status) **só** do contexto desta mensagem: inputs, skill, conhecimento injectado.
2. Se o dado não estiver no contexto: diz que **não tens** esse dado. Nunca o inventes nem o completes de memória.
3. Cita a fonte de cada facto: `[Fonte: …]` ou o path do artefacto.
4. Marca como **(hipótese)** o que não é suportado pelo contexto.
